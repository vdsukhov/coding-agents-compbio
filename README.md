# Coding agents for computational biology

Course website. Served with GitHub Pages from the repository root.

- `index.html` is the course home page.
- `lessonN/index.html` is each lesson page.

To publish a new lesson: add `lessonN/index.html`, then in `index.html` switch that lesson's card from "Coming soon" to a link (instructions are in a comment above the lesson list).
