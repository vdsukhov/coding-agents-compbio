A five-lesson course

Coding agents for computational biology

Start with how a language model predicts the next token. Finish with an agent that analyses single-cell data and builds a tested web tool. Each lesson reuses what the previous one built, and the same PBMC 3k dataset runs through all five.

Running through every lesson

Three ideas to keep in mind

One datasetPBMC 3k marker genes in lesson 2, its full analysis in lesson 4, a viewer for it in lesson 5.
Check everythingScore the output, test the agent, compare with known biology, then make the checks automatic.
Same loop, different modelThe loop you write in lesson 3 is the loop inside Claude Code. Swapping models shows how much the model does.
Before lesson 1

Install these first

Setup takes longer than you expect. Do it before the first lesson.

  • LM Studio 0.4.1 or later, with one small model downloaded · lesson 1
  • Python 3.11 or later with uv · lesson 1
  • A tool-capable model of 7B parameters or more · lessons 2–3
  • Docker, checked with docker run hello-world · lesson 3
  • git and a GitHub account · lessons 3–5
  • Node.js for the web viewer · lesson 5
